# Changelog

## 1.1.1 (unreleased) — executed composition, useful repair and explicit evidence

This is the v1.1 research release, using the fresh 1.1.1 identity after
withdrawal of v1.1.0. It includes breaking Rust API and JSON changes relative
to v1.0.0; the minor release number is not a claim of backward compatibility.
Consumers should review the [migration guide](docs/migration-v1.1.md).

### Executed composition

- Connect instrumented synthetic deliveries to the existing kernel-typed joint
  capability predicate with a proved execution refinement.
- Preserve the exact forbidden property across an equal-length action control
  and a useful stateful repair, with explicit context and scoped-authority witnesses.
- Generate the complete finite policy table from Lean; add an offline CLI,
  typed signed replay integration, independent effect reconstruction, and a
  conventional full-context comparator that agrees on the modeled decisions.
- Prove that exact next-request decisions on reachable safe contexts require
  three observation values: one bit is insufficient and two exposure bits suffice.
- Exhibit missing delegation as an observation ambiguity and distinguish
  governance decisions from what a monitor knows.
- Supply a static no-upload reader, an offline executable bundle path, and
  semantic, wire, signature, scope and evidence mutation controls.

### Trajectory and source evidence since 1.0

- Add versioned trajectory normalization, anchored hash replay, policy decisions,
  signed captures and controlled composition fixtures, with explicit source,
  policy and producer bindings. These include historical ordinal experiments;
  the executed-composition experiment supplies the action-sensitive result.
- Add source-bound Codex capture/adaptation machinery with Linux path and output
  controls. This is infrastructure with explicit admission contracts, not a
  claim that the older genuine-capture transport is qualified by this release.
- Bind audit-agent fixture theorems and repaired alternatives to immutable
  reference graph bytes; compare evaluated Lean graphs against complete JSON
  fixtures and reject parity mutations.
- Derive audit activation and required sacrifices from actual compilation;
  distinguish successful compilation, actual sacrifices and other failures.

### Compatibility and correctness

- Replace the public boundary-assessment struct with explicit assessed and
  unassessed variants. Unknown source boundaries no longer appear as measured
  zero dependencies; graph-only input does not establish source completeness.
- Permit a null singular certificate format and report all actual required
  certificates. Embedded replay provenance uses identifiers rather than runtime
  fixture paths. See the migration guide for affected Rust/JSON consumers.
- Reject nonfinite/overflowing certificate comparisons and infeasible allocation
  totals; handle extreme finite proportional allocations.
- Check all owned executed-composition declarations for unsupported axioms,
  including private, unused and opaque declarations, with compiled controls.
- Rework the README entry point and separate runnable finite evidence from
  the abstract scaling results and source-to-model assumptions.

The historical Bool capability examples and ordinal fixtures retain their
stated boundaries. Principal continuity, general concurrent/distributed semantics,
the broader institutional trace schema, a genuine second extracted-harness
scaling substrate and a general per-graph scaling law are not added here.

## 1.1.0 — withdrawn

The briefly published 1.1.0 artifact was withdrawn. Its identifier is not reused
for changed contents. The corrected candidate is prepared under 1.1.1.
